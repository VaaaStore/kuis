A. RINGKASAN MATERI UTAMA
1. Pertemuan 1: Pengantar Algoritma, Pseudocode, Flowchart, dan Dasar Python.
   - Algoritma adalah urutan langkah logis, sistematis, dan berhingga untuk menyelesaikan masalah.
   - Karakteristik: Input, Output, Definiteness (tidak ambigu), Finiteness (berhenti), Effectiveness.
   - Pendekatan Input-Process-Output (IPO).
   - Representasi: Bahasa natural, Pseudocode, Flowchart, dan Kode Program.
   - Dasar Python: Variabel, Tipe Data (`int`, `float`, `str`, `bool`), fungsi `input()`, `print()`, dan operator dasar.

2. Pertemuan 2 & 4: Struktur Kontrol Seleksi (Percabangan)
   - Alur sekuensial berjalan lurus dari atas ke bawah, sedangkan percabangan mengambil keputusan berdasarkan kondisi Boolean (`True`/`False`).
   - Struktur percabangan Python: `if`, `if-else`, `if-elif-else`, dan `nested if`.
   - Operator Perbandingan (`>`, `<`, `==`, `!=`, `>=`, `<=`) dan Operator Logika (`and`, `or`, `not`).
   - Pentingnya indentasi (spasi) untuk mendefinisikan blok kode di Python.

3. Pertemuan 3: String, Bilangan, dan Operator
   - String bersifat *immutable* (tidak dapat diubah langsung isinya per indeks). Menggunakan indeks positif (dari 0) dan negatif (dari -1).
   - Operasi String: Slicing (`[:]`), penggabungan (`+`), perkalian (`*`), `len()`, escape characters (`\n`, `\t`), dan fungsi format (`.format()` atau `%`).
   - Bilangan: `int`, `float`, `complex`. Masalah presisi float dapat diatasi menggunakan modul `decimal` atau `fractions`.
   - Operator lengkap: Aritmatika, Perbandingan, Penugasan, Logika, Bitwise, Identitas (`is`, `is not`), dan Keanggotaan (`in`, `not in`).

4. Pertemuan 5: Perulangan (Looping)
   - Digunakan untuk mengeksekusi blok kode berulang kali.
   - Perulangan `for`: Mengiterasi objek berurutan (*sequence* seperti `string`, `list`, `tuple`) serta dikombinasikan dengan fungsi `range()`.
   - Perulangan `while`: Berjalan selama kondisi bernilai `True`. Perlu hati-hati terhadap *infinite loop*.
   - Kontrol Looping: `break` (keluar paksa dari loop) dan `continue` (melompati iterasi saat ini ke iterasi berikutnya).

5. Pertemuan 6: List dan Tuple
   - `list`: Tipe data berurutan yang bersifat *mutable* (dapat diubah), didefinisikan dengan kurung siku `[]`. Memiliki metode seperti `append()`, `extend()`, `insert()`, `remove()`, `pop()`, `sort()`, dll.
   - `tuple`: Mirip dengan `list` namun bersifat *immutable* (tidak dapat diubah), didefinisikan dengan kurung biasa `()`. Lebih cepat untuk iterasi dan aman dari perubahan data.

6. Pertemuan 7: Matriks dan Library Pandas
   - Matriks direpresentasikan di Python sebagai *list dua dimensi* (list di dalam list).
   - Operasi matriks dasar: Penjumlahan, pengurangan, dan perkalian matriks menggunakan *nested loop*.
   - Library `Pandas`: Digunakan untuk analisis data terstruktur dengan struktur data utama berupa `DataFrame` (tabel 2 dimensi baris dan kolom).

7. Pertemuan 8 & 9: Fungsi (Function)
   - Blok program yang dapat digunakan kembali (*reusable*) dengan kata kunci `def`.
   - Komponen fungsi: Nama fungsi, parameter/argumen, *docstring*, blok pernyataan, dan `return`.
   - Jenis Argumen: Argumen wajib, Argumen kata kunci (*keyword argument*), Argumen default, dan Argumen panjang sembarang (`*args`).
   - Ruang lingkup variabel (*scope*): Variabel *Global* (di luar fungsi) dan *Local* (di dalam fungsi).
